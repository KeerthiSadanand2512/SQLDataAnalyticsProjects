# Sales Performance Tracker

## Objective
Analyze sales data to identify revenue trends, top-performing products, regional performance, and customer purchasing behavior.

## Skills Demonstrated
- SQL Joins
- Aggregations
- Window Functions
- CTEs
- Business KPI Analysis

## Project Structure
- data/ : datasets
- sql/ : SQL scripts
- dashboards/ : Power BI dashboard files
- images/ : dashboard screenshots
- reports/ : project findings
